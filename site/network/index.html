The network

A small neural network that watches a rover's position reports and flags the ones that look wrong, compared with the simple statistical test it would replace. This page will show what it learned and how.

What this page will hold

  • The loss landscape in 3D: the training loss over two directions in weight space, with the path gradient descent took across it and a scrubber over the training epochs.
  • Inside the network: its layers, with the activations for an example you choose.
  • The honest comparison: the simple method it is measured against, and the test scores that matter for rare faults (how many it catches, how many alarms are false, and how long it takes to notice).
  • Where it runs: the rover's computer in a cutaway, the inputs it reads (the ranging radio and wheel odometry) and the safety check it feeds.

Nothing on this page is a result yet: the network is still being trained and tested.
