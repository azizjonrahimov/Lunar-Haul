What a run record holds

The engine version and git commit (and whether the code had uncommitted changes), the Python and platform, the scenario and its hash, the seeds, the hashes of every data file the engine read (landing-outcome tables, driving tables, terrain), and the hash of the output. Replicating re-runs the stored inputs and compares output hashes, so “replicated ✓” means the same bytes came out. Only runs of a clean, tagged release rank on the leaderboard.
