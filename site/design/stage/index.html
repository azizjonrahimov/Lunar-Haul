Measurements

Each "Measure 150 frames" run holds the adaptive resolution still, warms the GPU up, then draws 150 frames at the current view, one per task, each inside a GPU timer query, and logs the GPU and CPU time per frame (p50 and p95). A real frame overlaps the two, so its cost is about the larger one; the frame budget at 60 Hz is 16.7 ms. The live readout above shows the frame interval, which the display's refresh rate caps and which a browser throttles when its window is in the background.
