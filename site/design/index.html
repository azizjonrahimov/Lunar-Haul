Typography

Source Sans 3 stays the reading face. Sora (display) sets titles, labels and pills; it read better than Space Grotesk at 12–14 px in the F-30 A/B. JetBrains Mono sets every number, with tabular figures.

Contrast, computed now

Every colour pair the components use, read from the CSS variables in this browser and checked against WCAG 2.2: 4.5:1 for text, 3:1 for text of 24 px and larger, focus rings and marks (1.4.3, 1.4.11). In the instrument theme, text sits on glass, so the panel colour is composited over each backdrop the way the browser paints it; white is the worst case (a sunlit hull, bloom).
